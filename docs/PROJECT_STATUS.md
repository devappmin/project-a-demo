# 프로젝트 현재 상태

## 기준

- 엔진: Godot 4.7
- 메인 씬: `res://app/bootstrap/app_root.tscn`
- 화면: 640×360, 정수 스케일, nearest filtering
- 런타임 네트워크 의존성: 없음

## 현재 플레이 가능 범위

- 타이틀에서 새 게임 또는 6행 불러오기
- 기초 방과 기초 홀 이동
- 거울 상호작용과 이름·초상화·표정·선택지 대화
- 중요 선택 자동 저장과 정확한 대화 재개
- 자동 저장 1개, 수동 슬롯 5개, 백업 복구

## 구현 완료

### 플레이어와 월드

- 이동, 달리기, 충돌, 방향 애니메이션과 상호작용 감지
- 영속 플레이어와 맵 전환, 스폰, 페이드, Y-sort 재결합
- 맵별 오브젝트 상태 캡처와 복원

### 대화와 작성 데이터

- 트리거와 조건 우선순위로 이벤트를 선택하는 대화 런타임
- 화자 이름·초상화·표정·선택지·효과와 안정 경계 체크포인트
- 한국어 문서에서 정규화된 작성 JSON과 생성 스냅샷으로 이어지는 작성 흐름

### 저장과 메뉴

- 자동 저장 1개와 수동 슬롯 5개, 슬롯 메타데이터와 덮어쓰기 확인
- 맵·플레이어·내러티브·월드·진행 중 대화의 트랜잭션 복원
- 손상된 현재 저장의 백업 복구와 실패 시 기존 플레이 보존

### 검증

- Python 단위 테스트와 32개 Godot 테스트 스위트
- 에디터 로드와 헤드리스 부팅 검증
- 사용자가 실제 키보드와 화면으로 13단계 수동 수락을 완료함: 슬롯 복원·재저장, 활성 자동 저장의 대화 재개, 백업 복구, 오프라인 재실행·불러오기, 자동 저장 메타데이터 확인을 포함함

## 현재 콘텐츠

- 맵: `foundation_room`, `foundation_hall`
- 상호작용: 거울, 왕복 문
- 캐릭터 정의: 레티, 젤리뽀

## 아직 구현되지 않음

- 범용 아이템과 인벤토리
- 아이템 획득과 사용
- 완전한 NPC·장소 조건 이벤트 규칙
- 플레이어용 퀘스트 진행 표시
- 오디오, 설정, 게임패드, 배포 자동화

## 알려진 제약

- 현재 콘텐츠는 기반 검증용 수직 슬라이스 규모다.
- 실제 맵 아트와 오디오는 데모 완성도 마일스톤 범위다.

## 표준 검증

```bash
python tools/project.py check
python tools/project.py test --filter dialogue
```

Godot을 찾지 못하는 환경에서는 `--godot`으로 Godot 4.7 실행 파일을 명시한다.
