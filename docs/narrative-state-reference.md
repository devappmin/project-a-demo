# 서사 상태·대화 용어 참고서

## 사건 상태
### 거울을 자세히 봄 (`mirror_seen`)
낯선 거울을 자세히 조사했는지 나타냅니다.
- 기본값: 거짓
- 별칭: 거울을 봄

### 열쇠를 보여줌 (`showed_diary_key`)
젤리뽀에게 교환일기 열쇠의 존재를 공개했는지 나타냅니다.
- 기본값: 거짓
- 별칭: 교환일기 열쇠를 보여줌


## 수치 상태
### 젤리뽀의 신뢰 (`jellyppo_trust`)
젤리뽀와 레티 사이의 신뢰도입니다.
- 기본값: 0.0; 범위: -10.0 ~ 10.0


## 소지품
### 교환일기 열쇠 (`exchange_diary_key`)
젤리뽀 관련 교환일기를 여는 열쇠입니다.
- 기본값: 0.0; 범위: 0.0 ~ 1.0
- 별칭: 일기 열쇠


## 퀘스트
### 진실 조사 (`truth_investigation`)
진실을 조사하는 이야기 진행 단계입니다.
- 기본값: not_started; 단계: 시작 전 (`not_started`) — 별칭: 아직 시작하지 않음, 조사 중 (`started`) — 별칭: 진행 중, 조사 완료 (`resolved`) — 별칭: 완료
- 별칭: 진실을 조사함


## 수집품
- 등록된 항목이 없습니다.

## 대화 트리거
### 거울 조사 (`mirror.inspect`)
거울을 조사할 때 사용하는 대화 트리거입니다.
- 별칭: 거울 살피기


## 명령
- 등록된 항목이 없습니다.

## 중요 선택 자동 저장
선택 직후의 결과와 자동 진행이 안정된 대사·선택지 경계까지 성공한 뒤 저장해야 하는 선택에는 선택지 블록 인용문에 `자동 저장: 중요 선택`이라고 씁니다. 이 인용문이 없으면 자동 저장하지 않습니다. 등록되지 않은 다른 한국어 값은 가져오기 오류입니다.

## 등장인물과 표정
- 젤리포 (`jellyppo`): 무표정 (`neutral`) — 별칭: 평온, 불안 (`uneasy`) — 별칭: 당황
- 레티 (`retti`): 무표정 (`neutral`) — 별칭: 평온, 불안 (`uneasy`) — 별칭: 걱정
