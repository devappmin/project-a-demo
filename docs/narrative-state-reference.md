# 서사 상태·대화 용어 참고서

## 사건 상태
### 거울을 자세히 봄 (`mirror_seen`)
낯선 거울을 자세히 조사했는지 나타냅니다.
- 기본값: 거짓
- 별칭: 거울을 봄

### 열쇠를 보여줌 (`showed_diary_key`)
젤리뽀에게 교환일기 열쇠의 존재를 공개했는지 나타냅니다.
- 기본값: 거짓
- 별칭: 교환일기 열쇠를 보여줌


## 수치 상태
### 젤리뽀의 신뢰 (`jellyppo_trust`)
젤리뽀와 레티 사이의 신뢰도입니다.
- 기본값: 0.0; 범위: -10.0 ~ 10.0


## 소지품
### 교환일기 열쇠 (`exchange_diary_key`)
젤리뽀 관련 교환일기를 여는 열쇠입니다.
- 기본값: 0.0; 범위: 0.0 ~ 1.0
- 별칭: 일기 열쇠


## 퀘스트
### 진실 조사 (`truth_investigation`)
진실을 조사하는 이야기 진행 단계입니다.
- 기본값: not_started; 단계: not_started, started, resolved
- 별칭: 진실을 조사함


## 수집품

## 대화 트리거
### 거울 조사 (`mirror.inspect`)
거울을 조사할 때 사용하는 대화 트리거입니다.
- 별칭: 거울 살피기


## 명령
