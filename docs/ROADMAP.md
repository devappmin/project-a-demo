# 프로젝트 로드맵

## 운영 규칙

- 목표: 플레이어가 실제로 경험할 결과와 저장 가능한 상태 변화를 기준으로 작업을 자른다.
- 플레이어 결과: 진행 상황과 다음 행동을 문서만으로 이해할 수 있다.
- 완료 조건: 각 마일스톤은 자동 검증과 해당하는 수동 플레이 확인을 남긴다.
- 제외 범위: 문서에 없는 시스템 확장과 임의의 콘텐츠 증가는 다음 마일스톤으로 미룬다.

## 완료: 게임플레이 기반과 대화 런타임

- 목표: 이동·상호작용·대화의 최소 실행 경로를 만든다.
- 플레이어 결과: 이동해 대화를 시작하고 선택지를 진행할 수 있다.
- 완료 조건: 입력, 상호작용, 대화 그래프, 선택 효과의 자동 테스트가 통과한다.
- 제외 범위: 저장, 여러 맵, 범용 인벤토리와 완성 콘텐츠.

## 완료: 문서 우선 대화 작성

- 목표: 한국어 문서에서 검증 가능한 대화 데이터를 만든다.
- 플레이어 결과: 조건과 선택 결과가 대화에 반영된다.
- 완료 조건: 정규화 JSON, 스키마·컴파일러, 그래프·이벤트·source map·manifest 스냅샷이 일관되게 생성된다.
- 제외 범위: 온라인 동기화와 런타임 네트워크 접근.

## 완료: 월드·저장 수직 슬라이스

- 목표: 맵 전환부터 저장 복원까지 하나의 실제 플레이 흐름을 검증한다.
- 플레이어 결과: 방과 홀을 오가고 자동 저장과 수동 저장으로 정확히 돌아올 수 있다.
- 완료 조건: 6개 저장 행, 백업 복구, 활성 대화 재개, 오프라인 재시작·불러오기와 13단계 실제 키보드 수락이 확인된다.
- 제외 범위: 일반 아이템 루프, 퀘스트 UI, 오디오와 배포.

## 완료: 문서·인수인계 이식성

- 목표: 새 개발 환경에서도 실행·검증·구조를 빠르게 파악할 수 있게 한다.
- 플레이어 결과: 개발 변경이 현재 플레이 가능 범위를 손상시키지 않는다.
- 완료 조건: 휴대 가능한 프로젝트 명령과 상태·로드맵·아키텍처 문서가 추적된다.
- 제외 범위: 게임 기능 추가와 특정 운영체제 전용 설치 안내.
- 검증 근거: README 온보딩, `tools/project.py check`, 공유 `AGENTS.md`·`CLAUDE.md` 규칙, 저장소 작업 스킬 검증, 저장소 밖 교차 디렉터리 호출을 모두 확인함.

## 다음: 조건 분기 플레이 기반

- 목표: 인벤토리 상태, 아이템 획득·사용·소비, 퀘스트 단계 전환, 조건부 이벤트 선택, 대화 조건·효과를 하나의 상태 모델로 연결한다.
- 플레이어 결과: 소지품과 선택, 퀘스트 진행에 따라 만나는 이벤트와 대화가 달라진다.
- 완료 조건: 획득·사용·소비와 퀘스트 단계 전환, 조건부 이벤트 선택, 대화 조건·효과, 저장·불러오기 왕복, 실패 원자성이 자동 테스트와 플레이 확인으로 검증된다.
- 제외 범위: 장편 시나리오, 최종 밸런싱, 실제 맵 아트와 오디오.

## 이후: 젤리뽀의 집 플레이어블 시나리오

- 목표: 조건 분기 기반을 완결된 한 장소 시나리오로 검증한다.
- 플레이어 결과: 첫 방문, 아이템 소지 방문, 요구 조건 충족 방문에서 서로 다른 이야기와 선택을 경험하고 다시 합류한다.
- 완료 조건: 첫 방문, 아이템 소지 방문, 요구 조건 충족 방문, 선택 뒤 여러 문단, 이후 선택, 재합류가 모두 테스트와 플레이 확인에서 재현된다.
- 제외 범위: 여러 장소의 대규모 콘텐츠와 다중 엔딩 전체.

## 이후: 콘텐츠 제작 확장

- 목표: 검증된 작성 흐름으로 캐릭터·장소·퀘스트 콘텐츠를 늘린다.
- 플레이어 결과: 여러 장소에서 연결된 조사와 대화 진행을 경험한다.
- 완료 조건: 새 콘텐츠가 문서·생성 스냅샷·조건 검증을 거쳐 회귀 없이 동작한다.
- 제외 범위: 출시 품질의 모든 아트·사운드·플랫폼 지원.

## 이후: 데모 완성도와 배포

- 목표: 플레이 가능한 데모를 품질과 배포 관점에서 마무리한다.
- 플레이어 결과: 일관된 아트·오디오·설정과 배포 가능한 데모를 받는다.
- 완료 조건: 실제 맵 아트와 오디오, 설정·게임패드, 배포 자동화, 최종 회귀 검증이 완료된다.
- 제외 범위: 데모 이후의 확장 시나리오와 라이브 운영.
